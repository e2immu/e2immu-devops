= Reference

This appendix contains reference information and additional resources.

== Configuration Reference

Complete list of configuration options:

[cols="1,2,1,3"]
|===
|Parameter |Type |Default |Description

|server.port
|integer
|8080
|Port number for the server

|server.host
|string
|localhost
|Hostname or IP address

|database.url
|string
|_required_
|Database connection URL

|database.pool.max
|integer
|10
|Maximum connections in pool
|===

== API Reference

=== User Management

==== GET /api/users
Returns list of all users.

*Response:*
[source,json]
----
[
  {
    "id": 1,
    "name": "John Doe",
    "email": "john@example.com"
  }
]
----

==== POST /api/users
Creates a new user.

*Request body:*
[source,json]
----
{
  "name": "Jane Smith",
  "email": "jane@example.com"
}
----
